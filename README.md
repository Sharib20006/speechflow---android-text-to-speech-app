# speechFlow

**speechFlow** is an Android text-to-speech (TTS) engine that provides seamless access to the popular **ETI Eloquence / IBM TTS voice**, based on the **Evdroid** project.

It includes several enhancements focused on improving pronunciation, reducing speech latency, simplifying settings, and providing a more comfortable experience for everyday users.

**Modder:** Syed Sharib Ali

---

## Features

### 1. Hindi Language Support

- Added Hindi language support with original Hindi phonemes and acoustics.
- Hindi pronunciation improvements are based on the open-source **eSpeak** project.
- Designed to provide clearer and more natural Hindi speech.

### 2. Improved Speed and Reduced Latency

- Optimised speech processing to reduce delays caused by library limitations.
- Improved startup performance.
- Speech now works more smoothly with minimal initial delay.

### 3. Repeating Character Support

- Supports counting repeated characters instead of announcing the same character repeatedly.
- Helps make repeated symbols and characters easier to understand.

### 4. Original Speech Options Retained

- Retains the speech options originally provided by the developer.
- Existing users can continue using the familiar speech controls.

### 5. Organised Settings

The settings layout has been organised into separate sections for easier access and better clarity:

- Speech Settings
- Text Processing Settings
- Dictionary Settings

### 6. Compatibility with Other TTS Apps

speechFlow is designed to work with applications such as:

- Auto TTS
- Other Android applications that support external TTS engines

If speechFlow does not work correctly with another application, try clearing that application's data and configuring the TTS engine again.

### 7. Community Dictionary Support

- Added support for using a community dictionary instead of the default dictionary.
- Users can enable or disable the community dictionary according to their preferences.

### 8. Language-Specific Dictionaries

- Supports adding and using dictionaries for specific languages.
- This allows users to customise pronunciation according to their language requirements.

### 9. Camel Case Normalisation

- Provides an option for camel case normalisation.
- Useful for users who frequently work with camel case text, such as:

  `ThisIsCamelCaseText`

### 10. Filter Typing Echo

- Added support for filtering typing echo.
- Useful for users who rely on direct-touch typing.
- Enable this option to avoid duplicate announcements of typed keys.

### 11. Emoji, Numbers, and Punctuation Customisation

speechFlow supports customisation options for:

- Emoji reading
- Intelligent number processing
- Punctuation reading

Users can adjust these options according to their preferences.

### 12. Additional Improvements

- Various other fixes and optimisations for smoother performance.
- General improvements to speech processing and usability.

## About This Project

speechFlow is a modified and enhanced version based on the Evdroid project. Its goal is to provide a smoother, more accessible, and more customisable speech experience while retaining the original voice and speech options.

The project focuses on:

- Better Hindi pronunciation
- Reduced speech delay
- Improved text processing
- Flexible dictionary support
- Easier settings navigation
- Better accessibility and everyday usability
